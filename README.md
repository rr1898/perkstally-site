# perkstally-site

Public pages for the PerksTally app, served by GitHub Pages from `main` at the repo root.

| Page | URL | Used for |
| --- | --- | --- |
| `index.md` | https://rr1898.github.io/perkstally-site/ | Marketing URL (optional) |
| `privacy-policy.md` | https://rr1898.github.io/perkstally-site/privacy-policy | Privacy policy URL (App Store and Google Play, required) |
| `support.md` | https://rr1898.github.io/perkstally-site/support | Support URL (App Store, required) |

These URLs are entered in App Store Connect and Play Console, so keep the file names stable. Edit a page and push to `main`; the site rebuilds in about a minute. When the app's data handling changes, update `privacy-policy.md` and its "Last updated" date.
